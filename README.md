## 🎮 Overview
Aqua Stomii is an engaging mobile endless scroller where players control a fish ascending through a perilous underwater environment. The core challenge lies in navigating upward through an unpredictable array of hazards while balancing the risk and reward of collecting coins and extra lives.

## ⚙️ Technical Highlights
Built with **C#** and **Unity 2D**, this project focuses on mobile-first design and dynamic entity management:

* **Procedural Generation System:** Engineered a dynamic spawner that randomizes the appearance, timing, and positioning of enemies, collectible coins, and health pickups (hearts). This ensures that no two playthroughs are ever the same, maintaining high replayability.
* **Mobile-Optimized Mechanics:** Designed for vertical aspect ratios (portrait mode) with responsive interactions tailored for mobile platforms.
* **Hazard & Entity Management:** Implemented independent physics and behaviors for various entities, including gravity-affected falling bombs, static wall urchins, and dynamic aquatic enemies.
